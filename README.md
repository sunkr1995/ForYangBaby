# 信用账户维持担保比例测算器

纯前端、本地实时计算的融资融券账户测算工具。账户金额不会上传、写入 URL 或持久化，刷新即清空。

## 功能

- 总资产、总负债、警戒线、平仓线及券商比例差异。
- 恢复目标可选平仓线、警戒线或自定义比例，附加比例默认0.03个百分点，可设为0；同时展示两档三种操作的六项对照。
- 根据可用现金、股票市值和外部资金区分可执行、不可执行、条件待确认和不需要补仓。
- 七项组合操作模拟，包含卖股净所得、交易费用及提取现金，展示前后资产、负债、净资产、恢复达标状态与操作后风险。
- 独立的还债后取现测算，默认取现后最低比例300%，支持自定义及资金可行性校验。
- 中文校验、演示数据、重置、结果复制和桌面/移动响应式布局。

## 技术栈

Vue 3 Composition API、TypeScript strict、Vite、按组件引入的 Element Plus、decimal.js、Vitest。无后端、路由、CDN、外部字体、远程 API 或统计脚本。

## 计算公式

A 为总资产，B 为总负债，R 为实际恢复目标的小数比例。实际恢复目标等于所选恢复比例加附加比例。例如选择警戒线140%、附加0.03个百分点，R 为1.4003。默认恢复到警戒线加附加比例。平仓线130%和警戒线140%用于独立判断风险。

| 项目         | 公式                          |
| ------------ | ----------------------------- |
| 当前比例     | A / B，B 为零时显示无负债     |
| 净资产       | A − B                         |
| 最低追加现金 | max(0, B × R − A)             |
| 最低外部还债 | max(0, B − A / R)             |
| 最低内部还债 | max(0, (B × R − A) / (R − 1)) |

内部还债公式仅适用于 R > 1、净资产大于零且当前未达标。净资产非正时标记不可行。达到实际恢复目标或无负债时三种金额均为零。当前比例低于平仓线时显示红色风险提示，介于平仓线（含）和警戒线之间时显示橙色提前预警，达到警戒线时显示绿色状态。模拟结果按精确值判断是否达到实际恢复目标，并同步显示操作后是否低于平仓线或警戒线。

模拟操作后资产为 `A + addCash − internalCashRepayment − stockRepayment − transactionFees − withdrawal`。
模拟操作后负债为 `B − externalRepayment − internalCashRepayment − stockRepayment`。
卖股净所得为 `saleAmount − transactionFees`，实际卖股还债不得超过净所得。合计还款不得超过负债。

### 还债后取现

Y 为拟取现金额，K 为取现后最低比例，默认3。使用账户内资产先偿还X，再取现Y。

```text
X = max(0, (K × B − A + Y) / (K − 1))
取现后资产 = A − X − Y
取现后负债 = B − X
```

X 向上取整到分后再次检查比例。X 不得超过负债，X+Y 不得超过资产，已知可变现资金需覆盖X+Y。缺少资金信息时显示条件待确认。全额清偿后以无负债处理。

独立取现页按当前账户测算，组合模拟会同时考虑全部操作。组合取现不能超过已有可用现金、追加现金与卖股净所得扣除内部还款后的余额。未知现金采用资产上限校验并保留待确认状态，卖出部分不与已有现金重复计入。仍有负债时，取现后的精确比例必须达到K。

取现比例K默认300%，参考用户提供的表格。附加比例按当前设置默认0.03个百分点，两者均可调整。

## 精度及业务假设

- 引擎金额单位为元，表单单位为万元。最多支持六位万元小数，对应 0.01 元。
- 金额、比例均使用 Decimal，精度为80位。所需金额向上取分，取整后再验证实际恢复目标。万元金额保留两位小数。最低补仓、还债金额向上显示至0.01万元，并提供精确到分的元金额，复制结果同步；操作后资产、负债及比例按精确最低金额计算。比例显示保留两位，达标与风险判断使用未舍入值。输入非负普通十进制字符串，单项引擎数值上限为 10²⁴。
- 平仓线必须大于100%，警戒线必须严格高于平仓线。默认平仓线130%、警戒线140%，均可按券商要求调整。
- 外部还债资金直接偿债，不加入当前账户资产快照。
- 已有现金还债使用原账户现金。新追加现金不用于同一次操作中的“已有现金还债”字段。
- 卖出价格等于当前资产估值，交易费用仅扣一次，未还债净所得仍留在账户内。仅卖股无费用时比例不变。
- 反向方案未计卖股费用。内部方案只评估已知可变现资产，不保证股票实际成交或净所得充足。
- 资金信息空缺时展示理论结果和条件待确认。已知资金足够覆盖理论金额时可判定可执行，已知完整资金不足时判定不可执行。
- 不模拟券商担保品折算、利息累积、税费明细、交易结算时间、停牌或流动性限制。
- 剪贴板功能需要安全上下文和浏览器权限，失败会显示中文提示。

## 文件结构

- `src/App.vue` 账户表单、风险状态、方案卡片、操作模拟、对比与复制。
- `src/style.css` 响应式视觉样式。
- `src/utils/marginCalculator.ts` 独立类型、解析、格式化、校验与纯计算函数。
- `tests/marginCalculator.test.ts` 基础公式及边界测试。
- `tests/recoveryAndWithdrawal.test.ts` 两档恢复、显示回算、模拟后预警与取现回归测试，使用虚构账户样例。
- `.github/workflows/deploy.yml` 自动验证与部署。
- `vite.config.ts`、`tsconfig.json`、`package.json`、`package-lock.json` 构建与依赖配置。

## 风险提示

本工具仅根据用户输入的资产、负债及设定比例进行数学测算，结果仅供参考。实际维持担保比例、担保品认定、融资负债、还款顺序及追保要求以证券公司规定和账户实际数据为准。本工具不提供投资建议。
